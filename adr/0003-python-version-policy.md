# 3. Record architecture decisions

Date: 2025-11-12

## Status

Accepted

## Context

We need to decide which versions of Python to target.

## Decision

We will target the last 2 stable releases of Python.
Updates will be made when convenient after a new version is releaseed.

## Justification

This is a toy project and is a good place to try new Python features.
Minimising the number of Python versions simplifies maintenance.

## Consequences

- Limit Python features to last 2 stable releases.
- Update to new releases when convenient.
