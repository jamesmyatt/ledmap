# 5. Compose Operations

Date: 2025-11-12

## Status

Accepted

## Context

We need to choose an API style.

## Decision

We will aim to work with composable operations.

## Justification

Composable operations describes well how an LED sequence
is transformed in the real-world into a resulting shape.
For example, rotations, mirroring, etc.

## Consequences

Use wrappers, like Gym.
