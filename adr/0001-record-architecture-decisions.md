# 1. Record architecture decisions

Date: 2025-11-12

## Status

Accepted

## Context

We need to record the architectural decisions made on this project.

## Decision

We will use Architecture Decision Records,
as described by Michael Nygard in this [article][1].
We will move the justification to a separate section.

## Justification

This is a popular, minimal template that we have used before.

Separating the justification leads to a more natural, easier to skim flow.

## Consequences

See Michael Nygard's article, linked above.

[1]: http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions
